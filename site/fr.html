macOS Tahoe sur Proxmox, en une commande.

Une ligne curl sur l’hôte Proxmox monte toute la VM macOS.

Installer Sources

Que remplace-t-il ?

Monter une VM macOS sur Proxmox à la main, c’est

  1. chercher une image OpenCore
  2. y greffer un SMBIOS crédible
  3. récupérer une recovery chez Apple
  4. la convertir
  5. deviner quel CPU virtuel l’invité acceptera

Ce script fait tout d’une traite, et choisit le modèle de CPU d’après ce que ton hôte sait réellement fournir, si bien que la même commande marche sur un Xeon AVX2 comme sur une vieille machine AMD.

Que lance-t-il ?

Cinq étapes, sur l’hôte Proxmox, en root.

  1. contrôles

    Vérifie Proxmox VE et VT-x/AMD-V, puis choisit le meilleur CPU virtuel que l’hôte peut présenter : fonctionne sur tout CPU Intel ou AMD, avec ou sans AVX2

  2. kvm

    Configure KVM : ignore_msrs=1, rendu persistant

  3. opencore

    Télécharge l’ISO OpenCore, génère un SMBIOS aléatoire neuf (numéro de série, MLB, UUID) correspondant à la version de macOS choisie et l’y injecte ; sur les hôtes sans AVX2 il ajoute aussi CryptexFixup pour que Tahoe s’installe quand même

  4. recovery

    Télécharge la recovery macOS officielle depuis les serveurs Apple, via macrecovery

  5. vm

    La convertit et crée la VM : q35, OVMF, disque et réseau VirtIO

Que puis-je régler ?

Lancé dans un terminal, il demande l’essentiel (version de macOS, stockage, RAM, taille du disque), Entrée acceptant les valeurs par défaut. Chaque réglage est aussi une variable d’environnement, qui saute la question correspondante ; sans terminal, les valeurs par défaut s’appliquent, donc l’automatisation reste non interactive.

De quoi ai-je besoin ?

7.2Proxmox VE 7.2 ou plus récent

  • un hôte Intel/AMD 64 bits avec la virtualisation activée
  • au moins SSE4.2 (AVX2 recommandé)
  • ~5 Go libres sur le stockage des ISO plus le disque de la VM
  • un accès Internet sur l’hôte et dans la VM

Comment la rendre autonome ?

Une fois macOS installé, ceci copie OpenCore sur la partition EFI de la VM, détache les supports d’installation et redémarre la VM depuis son disque. À lancer sur l’hôte Proxmox.

iCloud / iMessage (facultatif)

Le script génère déjà un SMBIOS aléatoire par VM, suffisant pour l’installeur et les mises à jour logicielles. Les services Apple exigent en plus un hyperviseur masqué : ajoute VMHide dans EFI/OC/Kexts et dans config.plist, avec vmhState=enabled dans les boot-args, puis redémarre la VM avant de te connecter. Vérifie d’abord le numéro de série généré sur la page de couverture Apple : se connecter aux services Apple depuis une VM peut enfreindre les conditions d’Apple, et un numéro qui ressemblerait à celui d’un vrai appareil doit être régénéré avec GenSMBIOS.

Qu’est-ce qui coince ?

Les cinq choses qui coincent vraiment.

Choisi automatiquementCPU virtuel

Un CPU virtuel Intel générique correspondant à ce que l’hôte peut fournir : Haswell-noTSX-IBRS avec AVX2, SandyBridge-IBRS avec AVX seul, Nehalem-IBRS avec SSE4.2. On peut en forcer un avec CPU_MODEL=… (ex. CPU_MODEL=host).

“An error occurred preparing the software update”mise à jour

L’ISO OpenCore d’origine embarque un SMBIOS bouche-trou (iMac19,1, série à zéro) que l’installeur Apple refuse. Le script en génère désormais toujours un vrai ; supprime le cache /root/macos-tahoe-installer/opencore-boot-<version>.img et relance pour le régénérer si la VM a été créée avant ce correctif.

Hôte sans AVX2sans AVX2

La VM démarre par un petit disque de boot OpenCore (sata1) porteur de CryptexFixup : aucune reconstruction d’ISO, et finalize le replie dans la partition EFI de la VM. Les mises à jour delta ne sont pas disponibles ; mettre à jour via les installeurs complets.

Redémarrage immédiatboucle de boot

Vérifie que cat /sys/module/kvm/parameters/ignore_msrs renvoie Y ; redémarre l’hôte après la première installation si besoin.

Pas de souris/clavier, affichage lentconsole

Utilise la console noVNC ; le passthrough USB peut s’ajouter ensuite. Un affichage lent est normal : la VM n’a pas d’accélération GPU. Le passthrough GPU est possible mais hors sujet ici.

macos-tahoe-proxmox repose sur LongQT-sea/OpenCore-ISO et acidanthera/OpenCorePkg.
